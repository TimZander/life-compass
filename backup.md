# Your answers, and how to keep them

Everything you write in this workbook is stored on the device you write it on. It is never
sent anywhere — there is no account, no server, and nothing to sign in to.

That is the point, and it is also the risk. A browser may clear storage it thinks is stale,
and removing the app removes what it was holding. A backup file is the only copy that
survives either.

## Keeping a copy

A backup holds every answer from every worksheet, not just one day's. Save one whenever
you have written something you would not want to write again.

The file is ordinary text and is not encrypted — anyone who opens it can read what you
wrote. Keep it somewhere you would keep a private notebook.

## Putting one back

Restoring reads a backup file and replaces every answer on this device with what the file
holds. Anything here that is not in the file is gone, and there is no undo.
